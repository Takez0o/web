Jak odpočet spustit nebo upravit

  1. Přihlas se na GitHub účtem, který má právo zápisu do repozitáře Takez0o/web.
  2. Klikni na tlačítko Otevřít ovládání níže.
  3. Klikni na Run workflow. V poli Co chceš udělat vyber akci. Konec a zprávu vyplň jen tehdy, když je chceš změnit. Konec piš jako 9.12.2026 10:00.
  4. Potvrď zeleným tlačítkem Run workflow. Zhruba do dvou minut se změna objeví všem, i na už otevřených stránkách. Uvidíš ji i v rámečku nahoře.

Co jednotlivé akce dělají

Spustit odpočet zapne odpočet. Konec zůstává pevný, takže se odpočítává jen čas, který zbývá do konce.

Jen upravit konec nebo zprávu změní datum konce nebo závěrečnou zprávu a stav nechá, jak je.

Vrátit do stavu před spuštěním odpočet znovu skryje, třeba po omylu.

Ovládat odpočet může jen ten, kdo má v repozitáři právo zápisu. Ostatní tlačítko Run workflow vůbec neuvidí. Na telefonu použij prohlížeč. Kdyby tam tlačítko chybělo, přepni stránku GitHubu na verzi pro počítač.
